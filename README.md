# Keila Maria Unhas 💅

## Sobre o projeto
Sistema desenvolvido como projeto de extensão
do curso de Análise e Desenvolvimento de Sistemas.
Seu objetivo é auxiliar no gerenciamento de
agendamentos de uma manicure.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- Supabase
- Netlify

## Funcionalidades
- Autenticação de usuários
- Cadastro de agendamentos
- Consulta de agendamentos
- Exclusão de agendamentos
